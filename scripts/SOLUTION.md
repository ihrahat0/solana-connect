# How to Fix the TokenAccountNotFoundError

1. First, check your wallet's token accounts:
   npm run check -- YOUR_WALLET_ADDRESS

2. Create a token account for your wallet:
   npm run create -- YOUR_WALLET_ADDRESS

3. To get tokens, you need to contact the token creator (mint authority):
   - Mint authority address: 7v8UUEYC151uXUtBXKe49tVWfPPosSKoJaAfxr4H7jBX
   - Token address: FTGo5F681LepoU2qTasLtk325T2iX6F6onFHpvo5Hvci

4. Once you have tokens, you can send them in the app.

Note: Make sure your wallet is connected to Solana's devnet.
